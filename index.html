Babaclipz Uploader

A private desktop tool that publishes short GTA gaming clips to the owner's own YouTube channel as YouTube Shorts, with title, description, hashtags and a credit to the original creator, and reads the channel's statistics to learn which clips work best.

Developed with YouTube API Services. It has a single user, the channel owner, and is not offered to the public.
